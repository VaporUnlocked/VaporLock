VAPOR LOCK | AIM TESTING SUITE 1.1
PORTABLE WINDOWS x64 EDITION

START
Keep Aim Testing Suite.exe in a writable folder and double-click it.
Only the EXE needs to be copied. No installer, launcher, Python, .NET,
Visual C++ redistributable or separate asset download is required.
The included SWAT character, font and notices are
embedded in the EXE. The range does not unpack or launch a second program.

The models folder is created beside the EXE automatically. Add custom
.glb characters there, then reopen Esc to refresh the character choices.
These are 3D target models, not .onnx detection networks. See README.txt
inside models for format requirements.

The suite also creates reports, local settings and these text guides
beside the EXE. It does not install files into Windows, AppData or Temp,
register services, add startup entries, or require administrator access.
To move your saved settings and custom models, move the whole folder.
Copying only the EXE elsewhere starts a fresh portable setup.

CONTROLS
Click once to enter the range. Mouse looks; left click fires one shot.
W/A/S/D walk; Shift sprints; Ctrl crouches.
Esc opens the character, quality, unstuck, exit and project source menu.
F11 toggles borderless; F12 saves a clean range capture.
Shoot the physical settings panels to change the occupied bay's drill.
Only the occupied bay has active targets; other bays retain paused state.
Quality choices are Max, High, Mid (default) and Potato.

SYSTEM
64-bit Windows 10 or 11 with a working OpenGL 3.3-capable graphics driver.
The normal Windows and graphics-driver components are used; they are not
replaced or installed by this EXE. Keep the program in a location where
your account can create files. If it cannot create its local folders,
move it to a writable location instead of running it as administrator.

LOCAL OPERATION
No account, activation, license server, API, background download or port.
The explicit GitHub / Project source button in Esc opens the project repository
only when selected: https://github.com/VaporUnlocked/VaporLock
No detector, input injection or aim correction is included.

Third-party credits and licenses are in LICENSES.txt, which is included
inside the EXE and written beside it on first launch.
